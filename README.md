# rumi
Ein Werkzeug zur Anzeige des unternehmensdatenmodell, ein Nachweis, wo die Daten zu finden sind und mit welchen Dimensionen und Kennzahlen sie auszuwerten sind. 

## Beispieldaten
Die Besipieldaten sind mit den Willibald Daten der DDVUG e.V. entstanden. Diese Daten stehen unter www.dwa-compare.info und stehen unter der common createive Lizenz CC-BY-4.0 zur Verfügung.
